# Logicandy site

The privacy policy and help pages for Logicandy, served by GitHub Pages at
https://arieldelossantos.github.io/logicandy-site/ (English, Spanish and French).

Don't edit the pages here: they are written in the app repository's `site/` folder and copied
over with `tool/site/publish.sh`, which also keeps `.site-files` (the list of pages it copied).
